Vendor details
Grafana Labs Active

Grafana Labs ran a five-day AI Week (July 27–31), releasing one major capability per day at 16:00 UTC. The full set: Grafana Assistant Workspace (full-page AI planning and onboarding), Assistant Investigations (automated incident investigation), Assistant Automations (no-code remediation workflows), the Grafana Cloud MCP server (giving coding agents production context from telemetry), GCX (telemetry-driven instrumentation for AI apps), and Grafana Agent Observability (monitoring AI agent behaviour in production).

Grafana's 2026 Observability Survey found 92% of practitioners see value in AI anomaly detection but only 57% observe their own AI systems — a gap these tools explicitly address. The company is also positioned furthest in Completeness of Vision in the 2026 Gartner MQ for Observability Platforms.

Dynatrace Active

On July 27, Dynatrace announced major additions to Dynatrace Intelligence under the banner "Autonomous Operations for Enterprise AI." The headline features: an Autonomous SRE Agent that triggers on newly detected problems, enriches investigations, and links related incidents automatically; a Cloud SRE Agent that coordinates remediation across AWS, Azure, and Google Cloud; and an Agent Builder allowing customers to create custom AI agents without code.

Dynatrace's approach pairs its patented causal AI engine (deterministic root-cause analysis) with generative AI agents, positioning autonomous action as safe because it is grounded in causal context rather than probabilistic inference. The company also pursued FedRAMP High authorization and expanded its board with an AI and cloud veteran earlier in July.

New Relic Active

New Relic Autopilot — an out-of-the-box automated SRE agent that begins analysing an incident the moment an alert fires and drives toward root cause and safe remediation — reached general availability in late July 2026. Alongside it, New Relic Ground Truth became available: an AI-optimised data substrate that gives third-party agents (GitHub Copilot, Claude Code, AWS DevOps Guru, or custom orchestrators) direct programmatic access to New Relic's deepest observability insights.

Both capabilities were originally announced June 23 at the New Relic Advance 2026 event. New Relic also announced a user conference, RUNTIME at RenderATL, co-located with the developer event in Atlanta on August 12–13.

Splunk Active

Splunk was named a Leader in the 2026 IDC MarketScape for Worldwide SIEM, reinforcing Cisco's unified security platform story following Splunk.conf where the integrated Cisco + Splunk roadmap was showcased. In parallel, Splunk Enterprise Security 8.6 entered controlled availability with a suite of AI-powered security agents: a Detection Builder agent (natural-language SPL authoring), a Malware Reversing agent, a Phishing Analysis agent, and a Guided Response agent that recommends SOAR playbooks from investigation context.

Splunk also released a security advisory patching a critical CVE (CVE-2026-20253) affecting Splunk Enterprise versions below 10.2.4 and 10.0.7 via an OpenSSL upgrade.
