Grafana Labs Active

AI Week is underway (Jul 27–31), with new releases dropping daily at 16:00 UTC. Day 1 (Jul 27) shipped six generally available tools: Assistant Investigations, Assistant Workspace, Assistant Automations, the Grafana Cloud MCP server, gcx CLI, and Agent Observability.

Agent Observability gives teams running LLM agents in production a single place to monitor behaviour, trace conversations, track costs, and evaluate output quality. The Cloud MCP server gives AI agents native access to Grafana Cloud tooling at machine speed.

Dynatrace Active

On July 27, Dynatrace launched major advancements to Dynatrace Intelligence: an Autonomous SRE Agent for automated incident resolution, a Cloud SRE Agent for multi-cloud remediation across AWS, Azure, and GCP, and a no-code Agent Builder for creating custom AI agents without writing code.

The announcement deepens integrations with ServiceNow, Atlassian, and PagerDuty. Dynatrace's "deterministic AI" framing — auditable, governed, human-override-capable — is a deliberate contrast to probabilistic LLM approaches.

New Relic Active

Autopilot — New Relic's AI-driven incident investigation and root cause analysis tool — reached general availability this week, alongside Ground Truth for AI governance. An Autopilot Slack integration allows in-thread incident investigation without leaving Slack.

Smart alerts entered public preview, automatically monitoring entity alert coverage against recommended standards and enabling bulk condition creation.
