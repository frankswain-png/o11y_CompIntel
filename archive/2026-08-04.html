Grafana Labs Active

During Grafana AI Week (Jul 27–31, 2026), Grafana Labs shipped six generally available AI tools extending Grafana Assistant into a full agentic operations layer — detecting, investigating, and remediating production issues with minimal human intervention.

The six tools: Grafana Assistant Investigations (automated hypothesis generation and telemetry analysis), Grafana Assistant Workspace (full-page agent-native interface), Grafana Assistant Automations (runbook automation), Grafana Cloud MCP server (manage dashboards/alerts as code via any MCP-compatible client), gcx (agentic Grafana CLI), and Grafana Agent Observability.

Grafana's 2026 Observability Survey found 92% of practitioners value AI anomaly detection, yet only 57% are monitoring their own AI systems — framing these releases as closing that gap at the operator layer.

ClickHouse Active

On Aug 3, 2026, ClickHouse announced ClickHouse Labs, a new research group focused on foundational database science. Andy Pavlo — CMU professor, VLDB Early Career Award winner, Sloan Fellow, and father of the self-driving database concept (NoisePage/OtterTune) — joins as VP of Database Research.

ClickHouse Labs will publish research openly, covering autonomous databases, query processing, systems performance, and infrastructure for both ClickHouse and PostgreSQL workloads, testing everything against real production data.

This is a strategic long-game hire: Pavlo's work on ML-driven query optimisation and autonomous tuning could eventually be incorporated directly into ClickHouse's engine, compounding its query performance advantage over Elasticsearch and other log analytics stores.
